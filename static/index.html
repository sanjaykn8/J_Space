    TERMS

    Residual Stream
    The real hidden state carried and updated across your model's transformer layers (output_hidden_states).
    Logit Lens
    Unembedding an intermediate layer's residual stream through the model's own final norm + output projection, to read off what it currently "looks like" it's about to say.
    Concept score
    The logit the model's real unembedding matrix assigns to a tracked word, at a given layer and token position.
    J-Shield panel
    Reuses the same real concept scores — no SAE is trained in this project.
    Steering Vector
    A real contrastive-activation direction, added to the residual stream during generation.
    This tool runs real forward passes and generation against the model you load locally. It uses logit lens (a simple, well-known unembedding technique) as a stand-in for the more sophisticated, corpus-averaged Jacobian lens described in the Anthropic research on verbalizable / global-workspace-like representations that inspired this project — logit lens can be noisy, especially in early and middle layers. Steering uses a simple contrastive-activation-addition direction, not a trained latent guardrail. There is no SAE trained anywhere in this project.
